# clinet-server-TCP
Create-server realisation

Использование: g++ server.cpp socket_send_recieve.cpp -o server_app
               g++ client.cpp socket_send_recieve.cpp -o client_app

Создаем папки client/ и server/, в server/ должно что-то лежать. Далее эти файлы (можно несколько) мы подаем ./server_upp, одновременно с этим в client/ подаем желаемые имена итоговых копий.
